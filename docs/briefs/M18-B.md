## Contract
- **Sidebar** (`sessions` panel, title "Projects"): setting `sidebar.organize = "workspaces" | "projects"` (default `workspaces`).
  - `workspaces`: user workspaces (name, pin ★, counts, chevron) → their projects (repo/folder icon, name, counts) → sessions; then projects in no workspace; then Home with its sessions.
  - `projects`: flat list of projects (pinned first) → sessions; Home last.
  - Every **session row**: kind icon, title, live folder (last two path parts, `muted`), placement badge (`main` / `wt <branch>` pill, warning tint when shared), attention dot/count; tooltip with the full path.
  - Sort/filter controls keep working (sort applies within each level; filter matches workspace, project, folder, session).
- **Management** (all through the M18-A requests):
  - "+" menu in the panel header: New Workspace… (name + optional folders), Open Folder… (system panel → `project open`, with "Add to workspace ▸" submenu).
  - Drag a project row onto a workspace row → `workspace.assign`; drag it to the "No workspace" area → unassign.
  - Multi-select projects (⌘-click / ⇧-click) → context menu "New Workspace from Selection…".
  - Workspace context menu: Rename (inline edit), Pin/Unpin, Add Folder…, Delete Workspace (confirmation says projects are kept).
  - Project context menu: Rename, Pin, Move to Workspace ▸, Remove from Workspace, Reveal in Finder, Close (as today's workspace close rules).
- **Layouts and settings**: the layout belongs to the container the user switches to (workspace if the project is in one, else the project, else Home) — keep the M12-B park/restore mechanics keyed by that id. Settings layers: user < workspace (`<first project root>/.hutan/settings.toml`) < project (`<project root>/.hutan/settings.toml`, workspace-overridable keys only); `crates/settings` gains the third layer with hot reload.
- **⌘O / ⌘J**: ⌘O lists recent projects and "Open Folder…"; ⌘J lists workspaces, projects and sessions.
- Empty states with the mascot; theme tokens and `ui.rs` only.
