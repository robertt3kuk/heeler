## Behavior
- **Sidebar workspace list** (the sessions panel groups by workspace already): header with sort-mode menu (`manual` default · `recent activity` · `attention first` · `name`), pinned section on top, Home always first among unpinned in `manual`. Drag a workspace row to reorder (manual mode only; calls `workspace.move`); context menu: Pin/Unpin, Rename, Add folder…, Remove folder, Close (disabled with reason when live sessions), Reveal in Finder.
- **Filters** (settings `workspaces.hide_empty` default true, `workspaces.hide_sleeping` false, `workspaces.hide_cli_created` false, `workspaces.always_show_active` true; `workspaces.sort` persisted): a filter box at the top of the sidebar narrows by name/path; hidden workspaces stay reachable through ⌘J.
- **⌘O project picker**: recent projects (`workspace.recent`) with fuzzy filter, "Open Folder…" (NSOpenPanel via GPUI `prompt_for_paths`) → `workspace.open`; opening focuses the workspace.
- **⌘J jump palette**: workspaces + sessions across everything, including hidden ones; Enter focuses.
- **Per-workspace layout**: the workbench remembers a pane tree + dock state per workspace (desktop state file, ADR 0010); switching workspaces swaps the center pane tree without killing terminals (they stay attached or detach/reattach cheaply — measure and choose; terminals of other workspaces must not keep rendering). New sessions start in the active workspace's first root (already true for focused session; now follows the active workspace).
- **Workspace settings**: `<root>/.heeler/settings.toml` of the active workspace's first root layers over user settings (ADR 0010 layering exists — verify it follows the active workspace and hot-reloads on switch).
- ⌘K commands for all of the above; status bar shows the active workspace.
