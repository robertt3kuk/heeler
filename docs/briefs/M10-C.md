## Scope
`crates/terminal_view`, `crates/desktop`, small additive helpers in `crates/client`. No daemon/protocol changes (report gaps).

## Behavior
- Setting `terminal.blocks` (default `true`): when false, the terminal looks exactly as today.
- The shared terminal model keeps the block list for its terminal (initial `terminal.blocks` page on attach + `terminal.block` events; re-fetch after reconnect), mapped onto absolute line numbers of viewport + scrollback.
- **Overlay on the single grid** (never re-layout the grid): a thin left gutter (width from density tokens) with a colored bar per finished block (success / error tone from design.md, neutral while running), a separator line above each prompt, and a right-aligned chip on the prompt line: exit status (`✓` / `✗ 2`) and duration (`1.2 s`, `3 m`). Running block: subtle animated activity indicator in the gutter (respect Reduce Motion).
- Hover a block → actions bar: Copy command, Copy output, Collapse/Expand, Rerun (types the command + Enter into the session), Send to agent (disabled with "M4" hint for now).
- **Collapse**: a collapsed block's output rows are visually folded into one summary row ("… 241 lines, exit 0") inside the view; folding is view-only (never changes the PTY, scrollback, or what other clients see); state persists per terminal in the desktop state file.
- **Keyboard**: ⌘↑ / ⌘↓ jump to previous/next prompt (scrolls the viewport and highlights the block); ⌘⇧A selects the current block's output; ⌘⇧C copies it; palette commands for all actions.
- Selection across a block uses the existing selection model; "Copy output" uses `terminal.block_text` so it works beyond the loaded scrollback.
- Alt screen active (vim, htop, TUIs): overlay hidden, keys pass through unchanged.
- Overview previews show the gutter colors only (no chips).
- Inspector "Info" tab lists the last 20 blocks of the focused terminal (command, exit, duration, cwd) with click-to-jump.
