No protocol changes; the block index is a later slice.

## Behavior
- Applies only when the session runs the login shell (empty command) or the command's basename is `zsh`/`bash`/`fish`; never for other programs. Opt-out: `TerminalConfig.shell_integration: bool` (default true) + env `STAFFY_SHELL_INTEGRATION=0` in the session env disables it.
- The user's own startup files still run exactly as before (no edits to user files, no duplicated sourcing, original `ZDOTDIR` restored inside the shell, `XDG_DATA_DIRS` restored to the user's value for child processes).
- Emitted sequences: `OSC 133;A` at prompt start, `OSC 133;B` at end of prompt (before user input), `OSC 133;C` right before a command executes, `OSC 133;D;<exit>` after it finishes (also on empty Enter as `D` without code is acceptable per FinalTerm), `OSC 7;file://<host><cwd>` on every prompt (percent-encoded). Terminated with ST or BEL consistently.
- Must coexist with popular prompt frameworks (starship, oh-my-zsh, powerlevel10k, fish `fish_prompt` customizations): hook via `precmd_functions`/`preexec_functions` (zsh), `PROMPT_COMMAND` + `DEBUG` trap or `PS0` (bash ≥ 4.4), `fish_prompt`/`fish_preexec`/`fish_postexec` events (fish) — never overwrite user prompt functions.
- Nested shells: an inner shell started by the user inside a session gets integration only if it inherits the injection env (document what happens).
- `STAFFY_SHELL_INTEGRATION_VERSION` exported so later slices can detect support.

## Acceptance
- PTY tests per shell present on the machine (`/bin/zsh`, `/bin/bash` (3.2 on macOS — document limits; test with Homebrew bash if installed), `fish` if installed; skip with a message otherwise): spawn the shell with a throwaway `HOME` containing a user rc that sets a marker variable and a custom prompt; run `true`, `false`, `cd /tmp`; assert the sniffer yields A,B,C,D(0), A,B,C,D(1), OSC 7 with the new cwd, the marker variable is set (user rc ran exactly once), the custom prompt text is visible, and `ZDOTDIR`/`XDG_DATA_DIRS` seen by a child equal the user's original values.
- A test with a non-shell command (`cat`) gets no injection env.
