## Scope
`crates/desktop` only; reuse `task.create` / existing worktree requests. No daemon/protocol change (report a contract gap if one blocks you).

## Contract
- **One launcher, "Start…"** (a sheet in the visual-system-v2 style), opened by: a **▶ Start** button in each project row's hover actions and in the project header of the sidebar; ⌘⇧T (both keymap bases; replaces the old New Agent picker, which this sheet absorbs); ⌘K "Start Agent or Task…"; the Tasks panel's "New task" button; an empty project's empty state.
- Fields (keyboard-first, Tab order top to bottom, ⌘↩ starts):
  - **Project** (defaults to the focused one; fuzzy picker), shown with its repo root and current branch.
  - **What**: Agent chat (OMP / Claude Code / Codex / direct model — only installed+logged-in ones enabled; others show Install…/Log in… from D-2), Terminal agent (OMP/Claude/Codex TUI in a PTY), Plain terminal, Command.
  - **Model** for chats (the harness's model list; default the harness default).
  - **Prompt** (multi-line `TextInput` with vim mode when on, attachments via the R-1 composer chips are a stretch goal only if the composer component is reusable as is; otherwise text only).
  - **Where**: Main checkout | New worktree (branch name prefilled from the title: `hutan/<slug>`, base = current branch, editable) | Existing worktree (list). The shared-checkout warning shows when another live agent already works in the chosen checkout.
  - **Title** (prefilled from the prompt's first line).
  - **After** (dependencies, optional, collapsed under "More").
  - **Start now** (default) vs **Queue as task** (auto-start by `max_parallel`).
- Every start goes through `task.create` (+ `task.start` when Start now), so it shows in the Tasks panel, the monitor and the history like other tasks; the new session opens focused in the center.
- Starting several: "Start & new" (⌥⌘↩) keeps the sheet open with Project/What/Where kept and prompt/title cleared, for fan-out.
- Remove the separate New Agent picker and the Tasks panel's old inline form (clean cutover); palette entries that pointed to them now open the sheet with the right preset.
