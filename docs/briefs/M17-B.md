## Behavior
- **History panel** (registry id `history`, default in the left dock as a tab next to Sessions; movable like every panel): a search field (debounced 150 ms, runs `history.search`), filter chips (source: Heeler / Claude / Codex / OMP; role; date: 24 h / 7 d / 30 d / all; project: active workspace / all), result rows grouped by session (title, source icon/label, project/cwd, relative time, hit count) with the highlighted snippet (`«…»` markers from the index rendered as emphasis, never raw).
- Row actions: **Resume** (opens a new terminal session in the active workspace — or the workspace containing the hit's cwd via `workspace.open` — running the hit's `resume_argv`; disabled with a reason when absent), **Copy resume command**, **Reveal file** (for external transcripts, when the hit carries a path; otherwise hidden), **Open block** (Heeler block hits: focus the terminal and jump to the block if it still exists).
- **Disabled state**: when `history.status.enabled` is false the panel shows an explanation (what is read, that nothing leaves the machine, sources list) and an **Enable indexing** button (`history.set_enabled`), plus a link to settings. Status footer: rows, DB size, per-source last indexed, errors count; **Clear** and **Rebuild** with confirmation.
- **⌘K / ⌘J integration**: palette command "Search history…" focuses the panel's search field; typing `?` prefix in ⌘J searches history inline (top 8 hits, Enter = Resume when available, else focus panel on the hit).
- Settings namespace `history` (desktop side only: default filters, show snippets) — daemon-side settings stay in `daemon.toml` through `history.set_enabled`.
