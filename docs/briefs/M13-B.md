## Behavior
- **Agents panel** (registry id `agents`, default in the right dock in `default` and `overview` presets, movable): one section per session that has an observation tree (workspace › session title), the tree with indentation: state glyph + color (working = animated dot respecting Reduce Motion, blocked = attention color, idle, unknown = muted `?`, finished with outcome glyphs ✓ ✗ ⊘ ⏹), name/agent type, model, live duration (from `started_at_ms`, ticking once per second only while visible and something is running), usage when present labelled by `usage.kind` (e.g. "1.5k tok · context"), activity line truncated. Finished subtrees dim and collapse by default; blocked nodes always visible.
- **Filters** (settings `agents.show_finished` false, `agents.only_blocked` false, `agents.scope = active_workspace | all`): chips at the top.
- **Click** a node → focus its session (terminal item or chat item); for nodes with `transcript_path` show "Open transcript" (reveal in Finder) in the context menu; "Copy node id".
- **Badges**: session rows in the sidebar, tabs, and overview cards show a compact agent badge: running subagents count and a blocked marker when any node is blocked (rollup already in `SessionInfo.agent.blocked_sub`); tooltip lists blocked nodes.
- **Notifications hook for M6**: a single internal event (`AgentAttentionChanged { session_id, blocked_nodes }`) emitted when a node becomes blocked; M6 will turn it into a macOS notification. For now it only updates the status-bar attention count.
- ⌘K: "Agents: Show Monitor", "Agents: Show Only Blocked".
