## Contract
- **Project identity**: for a path, the deepest enclosing git repository's *common dir* (`.git` file → `gitdir:` → `commondir`, or `.git` directory), canonicalized; else the folder itself. Main checkout and worktrees share one project; submodules and nested repos are their own.
- **Auto-assignment**: `session.create`, `chat.create`, `task.start`, restore and `worktree.create` put the session into the project of its cwd, creating it (`kind: project`, name = repo folder name, root = main checkout root) when missing; an explicit `workspace_id` in the request still wins. A cwd outside any repo goes to a folder project only when it is not `$HOME` or `/`; `$HOME`, `/` and the Home folder go to Home.
- **WorkspaceInfo** gains `project: {common_dir?, root, group_id?}`; `SessionInfo` gains `folder` (current cwd from OSC 7, else start cwd) — placement stays as in M7-A.
- **Groups**: storage table, `group.create {name}`, `group.list`, `group.rename`, `group.delete` (projects become ungrouped), `group.move` (order), `group.pin`, `group.assign {workspace_id, group_id?}`; event `group.changed`. `workspace.list` order: pinned groups, groups, ungrouped projects, Home last-or-first as today.
- **Migration**: existing workspaces with one root become projects (their identity computed); with several roots → each root a project (sessions follow their cwd; layouts keyed by the first root's project), the old workspace becomes a group with its name and pin. Home stays Home.
- **CLI**: `hutan project ls|open <path>|rename|pin|unpin|close` and `hutan group ls|new|rename|rm|add <project> <group>|remove <project>`; `hutan ws` removed (clean cutover; docs updated); `hutan ls` shows the project and folder columns.
