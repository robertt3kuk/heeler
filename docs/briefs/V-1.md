# V-1: vim mode in Hutan's text inputs

Agent: implementer   Depends on: master `64d8e0a` (D-2)   Branch: slice/V-1

## Context
Read AGENTS.md, `docs/design.md` (visual system v2, § Keyboard defaults), code: `crates/desktop/src/workbench/chat/input.rs` (`TextInput`, the composer's buffer), `chat/view.rs` (`on_key`), the other text fields of the desktop (palette filter, modal prompt input `workbench/modal.rs`, settings sheet edit field, sidebar filter/rename, tasks form, attach form) — find them with `TextInput` / `on_key_down`. Zed's vim mode is the model for behavior (read its docs, not its GPL code).

## Scope
`crates/desktop` only (a `vim` module next to `TextInput`, hooks in the inputs that use it), settings, docs (`docs/design.md` § Vim mode). No daemon/protocol. Terminals are out of scope (programs there do their own thing).

## Contract
- Setting `editor.vim_mode` (bool, default **false**), live; ⌘K "Toggle Vim Mode".
- A reusable modal layer over `TextInput` (pure data, unit-testable): **Insert** (typing as today), **Normal**, **Visual** (charwise). Escape: Insert → Normal (caret moves left one like vim); in Normal, Escape does the field's own escape (dismiss palette/modal, clear composer focus) — i.e. the second Escape behaves as today.
- Normal: `h j k l`, `w b e`, `W B E`, `0 ^ $`, `gg G` (multi-line composer), counts (`3w`), `x X`, `dd dw de db d$ D`, `cc cw ce C`, `s S`, `r<c>`, `i a I A o O`, `u` / `⌃r` (undo/redo — add an undo stack to `TextInput` if it has none, also usable outside vim with ⌘Z / ⌘⇧Z), `yy yw y$ p P` (unnamed register + system clipboard when `editor.vim_use_system_clipboard`, default true), `.` repeat of the last change (at least for `x`, `dw`, `cw`+text, `dd`), `~`.
- Visual: `v`, motions extend, `d y c x`, Escape back to Normal.
- Single-line fields: `j k` do nothing, `dd` clears the line; Enter in Normal mode = the field's confirm.
- The composer with vim on: Enter/⌘Enter send rules unchanged in Insert; in Normal, Enter sends only if `chat.send_on_enter`.
- Mode indicator: a small `NORMAL` / `INSERT` / `VISUAL` pill in the composer footer and at the right of a focused single-line field; block caret in Normal/Visual, bar caret in Insert.
- Fields that start empty for typing (palette, rename prompt) open in **Insert**.

## Acceptance
- Unit tests of the modal layer: motions, operators with motions and counts, visual ops, undo/redo, `.` repeat, registers, single-line rules, word boundaries with Unicode (Cyrillic) text.
- GPUI tests: vim on → composer starts Insert, Escape → Normal shows the pill and block caret, `dd` clears, `u` restores, `i` types; palette filter in Insert first, Escape → Normal, second Escape closes; vim off → today's behavior byte for byte (existing chat/palette tests untouched).
- `just check` green; committed on `slice/V-1`.
