## Contract
- **Panel `resources`** (default: bottom dock in the default preset, hidden; ⌘K "Resources: Show Panel"; ⌥⌘R toggles): subscribes (`resources.subscribe`, interval from `resources.interval_ms`, default 2000) only while visible; unsubscribes when hidden.
- **Table**: grouped by session (title, project/folder, placement badge), expandable process tree under each (indent by depth): name, PID, CPU % (tabular figures, a thin bar in `accent_soft`), memory (MB), threads, command (truncated, full in tooltip), agent marker (mascot-orange dot) for processes that are agent nodes with their node label; a header row for `hutand` itself. Sort by CPU / memory / name (column header click); filter box (name/command/session). Totals per session in its row.
- **Actions**: per process — Interrupt (SIGINT), Terminate (SIGTERM), Kill (SIGKILL, confirmation), Stop/Continue (SIGSTOP/SIGCONT); per session — Stop session, Kill session (confirmation listing what dies); per agent node — Interrupt agent (root: interrupt turn; subagent: as M13-C allows, disabled with the reason when unsupported). Errors from the daemon (`forbidden`, `invalid_state`) show inline on the row.
- Context menu on session rows elsewhere (sidebar, tabs): "Show in Resources".
- Empty state with the mascot (sleep) when nothing runs; theme tokens and `ui.rs` components only.
