## Contract
- **B-4** `HistoryHit` gains optional `path` (the external transcript file; absolute) and, for Hutan block hits, `terminal_id` + `block_id`. The index stores them (schema migration of `index.sqlite` with a format bump: existing rows are re-indexed on next start, never a crash). History panel: "Reveal File" uses `path`; "Open Block" opens the terminal and jumps to `block_id` exactly (no `ts_ms` matching).
- **B-6a** `approval.resolved` and `AgentEventKind::PermissionResolved` gain optional `decided_by: {client_kind, client_name?}` (the kind/name of the client that answered; absent for expiry). Journaled with the event, so `chat.history` replays it. The chat view shows "Allowed once · from CLI" / "· from another window"; `hutan chat log` prints it.
- **B-6b** Streaming text survives a late join: the daemon keeps, per running turn, the coalesced partial text of the open assistant message (and reasoning) and journals a `message_partial {message_id, text}` snapshot at most every 500 ms and at turn end it is superseded by `message_end`. `chat.history` returns the latest partial for an unfinished message; a client opened mid-stream shows the full text so far and continues with live deltas (dedup by `message_id` + length). Bounded: one partial per open message, replaced in place (not appended) in the journal.
- **B-6c** "Load earlier" in the chat view: the first page is the newest `HISTORY_DEFAULT_LIMIT` events; scrolling to the top (or a "Load earlier" row) pages back with `before_seq` until `has_more` is false, keeping the scroll anchor. Virtualized list keeps memory bounded.
