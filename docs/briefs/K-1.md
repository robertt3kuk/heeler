## Contract
- **Base keymap** setting `keymap.base = "zed" | "hutan"` (desktop settings, default **"zed"**). `keymap.toml` user bindings still merge on top of the chosen base. "hutan" = today's table (kept for those who learned it).
- **Zed base** (macOS), map each to the Hutan action that matches; keep Hutan-only actions on keys Zed leaves free:
  - ⌘⇧P command palette (⌘K stays as an alias), ⌘P quick open = Jump palette (projects/sessions/workspaces), ⌘O open folder/project, ⌘, settings, ⌘⇧N new window/ws? (only if an action exists; otherwise leave unbound).
  - ⌘B left dock, ⌘R right dock, ⌘J bottom dock, ⌘⌥Y close all docks (new action `CloseAllDocks`), ⌃` toggle bottom terminal panel → map to `ToggleBottomDock`.
  - ⌘W close tab, ⌘⇧W close pane/stop (keep current semantics, check Zed's), ⌘⇧[ ⌘⇧] / ⌃Tab ⌃⇧Tab tabs (already), ⌘1…⌘9 tabs, ⌘⇧T reopen closed tab in Zed — Hutan: keep ⌘⇧T = New Agent unless a reopen action exists (document).
  - Splits like Zed: ⌘K ⌘← / ⌘→ / ⌘↑ / ⌘↓ (chords: GPUI multi-stroke) split in that direction; ⌘K ⌘W close all tabs of pane if an action exists; ⌘⌥← / → focus neighbor (keep), ⌘K ⌘Z? no.
  - ⌘= / ⌘- / ⌘0 font size if the terminal has it (add `IncreaseFontSize`/`DecreaseFontSize`/`ResetFontSize` actions over `terminal.font_size` if missing — they write the user setting).
  - ⌘⇧J next attention, ⌘⌥R resources: keep if free under Zed; otherwise move and document.
  - Verify there are no duplicate keys within one context (a unit test over both bases: no key bound twice in the same context, every action named exists).
- **Docks are visible controls**, like Zed's status bar: three small buttons at the right of the status bar (left dock, bottom dock, right dock icons) that toggle each dock and show pressed state; tooltip with the key of the current base. A hidden dock with no panels shows a disabled button.
- Palette entries show the binding of the active base.
- Settings sheet lists `keymap.base` as a dropdown; changing it rebinds live.

## Acceptance

- GPUI tests: with the default (zed) base, simulated ⌘J / ⌘R / ⌘B toggle the docks both ways, also while a terminal has focus; status-bar dock buttons toggle; switching `keymap.base` live changes what ⌘J does; ⌘K chords split.
