## Changes

### Connection and sessions
- The desktop owns one `Connection` (autostart `heelerd` found next to the `heeler-desktop` binary, else on `PATH`; `HEELER_HOME`/`HEELER_SOCKET` respected). Bridge `state()`/`notices()` into GPUI entities (a `SessionsStore` entity) on GPUI's executor.
- **One terminal model per terminal, many views**: a `TerminalSession` entity owns the `TerminalHandle` and the terminal model; every view of that terminal (pane tab, overview preview) renders from it. Refactor `terminal_view` minimally so a view can render from a shared model entity; acks go out after the first paint of any view showing the frame (hidden terminals stay paced at zero cost and catch up when shown).
- `ItemRef::Terminal { session }` items open real terminal views; `TerminalUpdate::Reconnecting` → `ViewStatus::Reconnecting`, `Gone(SessionRestarted { new_terminal })` → transparently re-bind, `Gone(EpochChanged | NotFound)` / session ended → `ViewStatus::Ended(..)` with actions Restart / Close.
- Closing the app keeps sessions running; relaunch restores the layout (existing persistence) and re-attaches every open terminal item; items whose session no longer exists show an ended placeholder.
- Session lifecycle from UI: New terminal (⌘T, in the focused workspace, cwd = workspace root or `$HOME`), Rename, Restart, Stop (⌘⇧W, confirm when running), Close tab = detach (⌘W). New agent / chat (⌘⇧T / ⌘⌥T) stay disabled with "M4/M5" hints.
- Attention for M2 (agent states arrive in M4/M7): `failed` (exit ≠ 0, signal, spawn failure) and `done` (exited 0, or a terminal notification) are **unread** until the session's view is focused; `idle` otherwise. Ignore bells/notifications replayed from before the desktop connected (they arrive in `Notice` after reconnects).

### Panels (replace placeholders; each has a settings namespace — design.md § Settings)
- `sessions` (`panels.sessions`): search, "Needs you" section, grouping (`workspace` | `state` | `none`), configurable row fields (`state`, `kind`, `title`, `placement` = cwd basename for now, `age`), click opens/focuses the session's tab, context menu (Open in split right/down, Rename, Restart, Stop, Copy id), `+ New session`.
- `overview` (`panels.overview`): cards per session (state, title, cwd, live preview rendered from the shared model at a reduced font size when `preview = "live"`), sort (`attention` | `recent` | `name`), card size, click → leave overview (restores the stashed layout) and focus that session.
- `inspector` (`panels.inspector`): session info for the focused item (id, kind, title, command, cwd, state with exit code/signal, terminal id, size, created); `approvals`/`changes` tabs present but empty with an M4/M7 note; `reveal_on_approval` stored for later.
- Status items: `connection` (connected / reconnecting n / stopped + epoch tooltip), `sessions` (count), `attention` (needs-you count; click → jump to next ⌘⇧J), `density`, `theme`, `palette_hint`; configured per preset via `layout.presets.<name>.status_bar`.

### Settings wiring
- One `SettingsStore` for the app; register namespaces: `appearance`, `terminal` (font, size, line height, theme name incl. `auto`, cursor, option_as_meta, copy_on_select, scroll_to_bottom_on_input → `TerminalViewSettings` with the resolved theme palette), `layout` (current preset + user presets; built-ins `default`/`focus`/`overview` always available), `panels.sessions`, `panels.inspector`, `panels.overview`.
- Hot reload applies live: density tokens, terminal font/theme on all views, panel options, status bar items, preset definitions. On terminal theme change call `terminal.set_colors` for every attached terminal.
- Keymap: replace the hard-coded table with defaults + `keymap.toml` via `settings::keymap`; rebind live on change.
- Workspace overrides: when the focused session's workspace has a root, `set_workspace_root(root)`.
- **Settings UI (⌘,)**: a sheet/window generated from `SettingsStore::schema()`: namespace list (search), fields by schema type (bool toggle, enum dropdown, number, string, string list editor), "Reset to default", errors panel from `errors()`, writes through `write_user`. Every panel's ⚙ opens its namespace. "Save layout as preset…" (palette + title bar menu) writes `layout.presets.<name>` from the current state.
