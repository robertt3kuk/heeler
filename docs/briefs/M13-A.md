## Contract
- **Model** per session: `AgentObservation { session_id, root: node_id, nodes: Map<node_id, AgentNode> }`, `AgentNode { node_id, parent?, kind: main|sub, source, agent, name?, agent_type?, state: working|blocked|idle|unknown, outcome?: completed|failed|interrupted|disconnected, liveness: alive|gone|unknown, model?, started_at_ms?, ended_at_ms?, last_activity_ms, activity?: String (≤ 200 chars, e.g. current tool), usage?: Usage { kind: String (source-specific, e.g. "omp.tokens", "claude.context", "codex.total"), input?, output?, cache_read?, cache_write?, reasoning?, context_tokens?, context_window?, cost_usd? } }` — every numeric optional, never zero-filled. Bounded: ≤ 256 nodes per session (oldest finished pruned), finished subtrees kept 30 min.
- **Reporting v2**: `agent.report` gains optional `node { id, parent?, kind, name?, agent_type?, outcome?, model?, activity?, usage? }`; absent ⇒ the root node (M3-B behavior unchanged; existing hooks keep working). `agent.release` with a node id ends that node (outcome from the report). `seq` monotonic per (session, source, node). State `done` from the roadmap maps to `idle` + `outcome: completed`.
- **Codex (Hutan-owned chats)**: the M4-A adapter feeds the tree from `thread/status/changed` (active+waitingOnApproval/UserInput ⇒ blocked), `Thread.parentThreadId`, `collabAgentToolCall.agentsStates`, `subAgentActivity`, `thread/tokenUsage/updated` (usage kind `codex.total`), `Turn.durationMs`. A completed tool call is not a completed child.
- **Protocol 0.10**: `agent.tree { session_id? }` → observations (all sessions when absent); event `agent.tree_updated { session_id, nodes_changed: [AgentNode], nodes_removed: [node_id] }` coalesced ≤ 4/s per session. Golden fixtures. `SessionInfo.agent` stays (root summary) for older clients.
- **Attention rollup**: a session needs attention if any node is blocked (subagents included); `hutan ls` shows `blocked (sub: <name>)`.
- **CLI**: `hutan agent report … [--node ID --parent ID --kind sub --name N --agent-type T --model M --activity A --usage-json '{…}' --outcome O]`, `hutan agents [--json] [--watch]` (tree view: indentation, state glyph, model, duration, tokens when present).
- **Integrations** (update installers; keep idempotent install/uninstall preserving others' entries):
  - **OMP extension**: report `ctx.agent` identity (`kind`, `id`, `parentId`, `name`) for main and sub instances (extension factories are rebound per child — verify in the installed source); states from `agent_start/end` (respect `willContinue`), approvals → blocked/working; model from `ctx.model`; usage/activity where available cheaply. Tests under Bun as in M3-B.
  - **Claude hooks**: replace the subagent counter with nodes keyed by `agent_id` (`SubagentStart` → working node, `SubagentStop` → idle + completed, `agent_transcript_path` kept), tool/permission hooks carrying `agent_id` update that node's activity/state, `PostModelSwitch` updates model. Do **not** install a status line in this slice (it would replace the user's); document `subagentStatusLine` as a later option.
- Passive reconstruction (OMP directory nesting, Claude `subagents/`, Codex `thread_spawn_edges`) is **out of scope** here (M13-C, after M17's adapters).
