## Contract

- Typography: UI sans = system font; prose font = "New York" with Georgia fallback, applied to assistant/agent message text and markdown prose in the chat view, empty states; mono = `terminal.font_family`. Sizes per the spec and density.
- Density table v2 applied (row heights, radii, terminal padding).
- Components restyled per the spec: sidebar rows, buttons (primary/secondary/ghost), tabs, pane headers, status bar, palette, popovers, menus (where GPUI draws them), modals, settings sheet, chat (no agent bubbles, user bubble, tool/approval cards, composer card with round send/stop), empty states with mascot images (thinking/success/error/empty/sleep where those states exist today).
- Terminal default palettes harmonized: `hutan-dark` background `#262624`, `hutan-light` background `#FAF9F5`, ANSI colors tuned for contrast on them (WCAG AA for normal text on the background for the 8 base colors except black/white as appropriate); the daemon is told the new colors (existing mechanism).
