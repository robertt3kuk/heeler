## Contract
- **Workspace fields** (additive on `WorkspaceInfo`): `kind: home | project` (exactly one `home`, created on first start; the existing `default` workspace is migrated into Home), `pinned: bool`, `position: i64` (manual order), `created_by: user | cli | agent`, `last_active_ms` (max of session activity: create, input, output bursts throttled to ≤ 1 update / 10 s), `live_sessions: u32`, `total_sessions: u32`.
- **Home**: bound to a folder from daemon config `daemon.toml` `[workspaces] home_folder` (default `~/Hutan` created `0700` if missing — never auto-create inside the user's existing folders); cannot be closed; can be renamed; new sessions without a workspace go to Home.
- **Projects**: `workspace.open { path }` → finds an existing workspace whose roots contain the path, else creates one named after the folder (git repo root if inside a repo, detected by walking up to `.git`); `roots` may hold several repos; `workspace.add_root` / `workspace.remove_root`.
- **Recent projects**: `workspace.recent { limit ≤ 50 }` → workspaces + closed ones remembered (`recent_projects` table: path, name, last_opened_ms), newest first.
- **Ordering**: `workspace.move { workspace_id, before: Option<WorkspaceId> }` (manual order; renumber positions), `workspace.pin { workspace_id, pinned }`. Sorting modes are a client concern; the daemon provides fields for all of them (manual position, last_active_ms, attention via sessions, name).
- `workspace.close` on a project with no live sessions removes it from the list but keeps it in recent projects; with live sessions → `invalid_state` (unchanged).
- Events: `workspace.updated` on every field change (coalesce `last_active_ms` changes).
- **CLI**: `hutan ws open <path>`, `hutan ws ls [--sort manual|recent|attention|name] [--all]` (default hides empty non-pinned workspaces except Home), `hutan ws move <id|name> --before <id|name>|--last`, `hutan ws pin|unpin <id|name>`, `hutan ws recent`, `hutan ws use <id|name>` (prints `export HUTAN_WORKSPACE=…` for scripts; `hutan new` honours `HUTAN_WORKSPACE`).
