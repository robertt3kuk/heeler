# M2 demo: GPUI workbench and terminal client

Manual checklist for the M2 exit demo (`docs/roadmap.md` § M2). Runs against a throw-away `STAFFY_HOME`, never your real `~/Library/Application Support/Staffy`. The orchestrator records each step with a window screenshot (`screencapture -l <window id>`); a human can follow the same steps by hand.

## 0. Setup

```sh
cd <repo>
cargo build --release -p staffy-cli -p staffy-daemon -p staffy-desktop
export PATH="$PWD/target/release:$PATH"
export STAFFY_HOME="$(mktemp -d /tmp/staffy-m2demo.XXXXXX)"
staffy daemon start
staffy new --title omp -- omp          # any agent TUI; `vim` works too
staffy new --title shell               # account login shell (fish/zsh/bash)
staffy new --title failing -- sh -c 'echo boom; exit 2'
```

Expected: three sessions in `staffy ls`; `shell` runs your account login shell (`dscl . -read /Users/$USER UserShell`).

## 1. Launch and attach

`staffy-desktop &`

Expected: native window, transparent titlebar, tinted sidebar with the three sessions (failing shows a red state), inspector on the right, status bar `staffyd connected · 3 sessions`.

## 2. Terminals in panes

Click `omp`, then ⌘D with omp focused, then click `shell` in the sidebar for the new pane.

Expected: OMP renders correctly (colors, block glyphs, status line); ⌘D opened a new terminal in omp's cwd; typing works in both, including Cyrillic; the active pane has a focus ring.

## 3. Rearrange

Drag the `shell` tab to the bottom edge of the omp pane; drag the Sessions panel tab into the right dock; ⌘B / ⌘⌥B toggle docks; double-click a tab to zoom and back.

Expected: splits and docks follow the drags; nothing restarts; layout survives step 7.

## 4. Overview

⌘⇧O.

Expected: only the board in the center; one card per session with a live preview (omp art, shell prompt, `boom` for failing with `exited · exit 2`). ⌘⇧O again restores the exact previous layout.

## 5. Settings live

Edit `$STAFFY_HOME/settings.toml`:

```toml
[appearance]
density = "comfortable"

[terminal]
font_size = 15
```

Expected within ~1 s: larger terminal font, comfortable spacing, status bar shows `Comfortable`. ⌘, opens the settings sheet showing the same values; changing one there writes back to the file with comments preserved.

## 6. Daemon controls

Click `staffyd connected` in the status bar.

Expected: popover with version, pid, uptime, sessions, socket and log paths, Restart / Stop / Open Logs, and the working-mode selector (Ask on quit · Keep sessions running · Stop daemon with the app).

## 7. Quit and restore

⌘Q → dialog (live sessions, mode `ask`) → **Keep sessions running**. Then `staffy ls` and relaunch `staffy-desktop`.

Expected: `staffy ls` still lists the sessions (daemon kept them); the app reopens with the same layout and re-attached terminals; no `staffy-desktop` crash report is created (`ls ~/Library/Logs/DiagnosticReports | grep staffy-desktop` count unchanged).

## 8. Daemon restart

Status popover → Restart Daemon → confirm.

Expected: terminals show "daemon restarted" ended states with Restart actions; status bar reconnects to a new epoch.

## 9. Clean stop

⌘Q → **Stop sessions & daemon**.

Expected: app exits 0, `staffy daemon status` exits 3 (no daemon), no orphan `staffyd`/shell processes.

`just bench` — every budget passes (`docs/perf.md`).
