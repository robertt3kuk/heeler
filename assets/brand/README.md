# hutan — ассеты бренда

| Папка | Что внутри |
|---|---|
| `01-logo-classic` | Первый логотип: иконка и горизонтальный логотип (`hutan_`) |
| `02-luxe` | Люкс-стиль: линейная эмблема, засечки, светлый/тёмный вариант, иконка |
| `03-modern` | 4 модерн-направления: geo, brackets `{ }`, pixel, gradient + общая доска |
| `04-nusantara` | Культурные стили Борнео/Суматры: даякский щит, батик, ваянг |
| `05-mascot` | Маскот-система: иконки (тёмная/светлая/акцент), favicon, лого с названием, 6 ракурсов, 8 состояний UX. `svg/` — исходники, `png/` — 2x с прозрачным фоном |
| `06-animated` | Анимированные SVG и демо-страница |
| `source` | Python-скрипты, которые генерируют всё выше |

## Состояния маскота

| Файл | Когда показывать |
|---|---|
| `state-success` | тесты прошли, деплой готов |
| `state-thinking` | загрузка, агент работает |
| `state-error` | ошибка сборки |
| `state-empty` | пустой список проектов/файлов |
| `state-focus` | режим концентрации |
| `state-wink` | онбординг, подсказка |
| `state-sleep` | простой |
| `state-404-hanging` | страница 404 |

## Анимации (`06-animated`)

- `hutan-idle.svg` — ожидание: моргает, дышит, шевелит хохолком
- `hutan-thinking.svg` — загрузка: крутит головой, водит глазами, точки «печатает»
- `hutan-success.svg` — успех по кругу: прыжок, искры, конфетти
- `hutan-success-once.svg` — успех один раз, потом остаётся довольным и моргает

Это обычные SVG с CSS-анимацией внутри: работают в `<img src="…">`, без JS и библиотек.
При системной настройке «уменьшить движение» анимации отключаются сами.

`demo.html` — живой пример «Задеплоить → думает → готово». Открыть через локальный сервер:

```
python3 -m http.server 8765 --directory 06-animated
```

затем http://localhost:8765/demo.html
